## ❄️ 블록체인 온라인 에어컨

블록체인 기술을 활용해 여러 사용자가 실시간으로 온라인 에어컨 온도를 함께 조절할 수 있는 웹 애플리케이션입니다.  
온도 변경 내역이 블록체인에 기록되어 누구나 조작 이력을 투명하게 확인할 수 있습니다.

## Function
- 전원 ON / OFF
- 온도조절
- 풍속조절
- 모드 설정 (냉방, 난방)

## Stack

- Solidity
- Truffle
